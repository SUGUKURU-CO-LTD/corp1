## 電話不通のお知らせ

`/news` の「通信障害による電話不通（9月10日復旧予定）」は復旧予定日を過ぎており、発生日も本文に未確認と注記されています。現状の案内として残すと誤表示になるため、このPRでは一覧から外しました。復旧済みとしてアーカイブするか、削除してよいか確認してください。

## /pricing の届出手数料表

職業紹介の手数料を届出手数料表と同じ区分・上限で載せる指示があります。手元に表の区分がないため、「求職者無料／届出済み手数料表の範囲」までとし、区分の転記はしていません。表の写し（公開してよい範囲）を共有いただければ追PRします。

## /kerja の終了求人

終了求人は速やかに削除する指示があります。カタログ JSON のどれが終了かは別資料がないため、このPRでは表現（gratis・許可番号・協力先・速さ禁止）のみ直し、件数の削除はしていません。終了IDの一覧があれば追います。
